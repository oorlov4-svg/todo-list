📝 Todo List App

A simple and responsive Todo List application for managing daily tasks efficiently.
Built with modern frontend technologies, focusing on clean UI, usability, and maintainable code structure.

🚀 Features
➕ Add new tasks
✅ Mark tasks as completed
❌ Delete tasks
✏️ Edit existing tasks
🔍 Filter tasks (All / Active / Completed)
💾 Data persistence using Local Storage
📱 Responsive design for mobile and desktop
🛠️ Tech Stack
HTML5 – semantic structure
CSS3 / SCSS – styling and layout
JavaScript (ES6+) – application logic
LocalStorage API – saving user data in browser
📂 Project Structure
/project-root
│── index.html
│── /css
│   └── styles.css
│── /js
│   └── app.js
│── /assets
⚙️ Installation & Usage
Clone the repository:
git clone https://github.com/your-username/todo-list.git
Open the project:
cd todo-list
Run in browser:
open index.html
